# Polymarket Data Crawler & Analyzer

This project provides a set of Python tools to crawl, analyze, and visualize market data from Polymarket. It includes scripts for automated data collection, statistical reporting, and generating visual price charts.

## Project Structure

- `crawler.py`: The core data collection engine. It searches for markets based on keywords, fetches historical price data from the Polymarket CLOB (Central Limit Order Book) API, and saves the results into a structured CSV file.
- `judger.py`: A data analysis and visualization tool. It reads the CSV generated by the crawler, provides statistical summaries (event counts, missing data, etc.), and generates time-series price plots for the most active markets.
- `test.py`: A command-line utility for interactive market search and precise historical data extraction for specific tokens.

## Prerequisites

Ensure you have Python installed, then install the required dependencies:

```bash
pip install requests pandas matplotlib seaborn tqdm
```

## Usage

### 1. Data Collection (`crawler.py`)

Configure your search keywords and time range directly in the `⚙️ 配置区域` (Configuration Area) of `crawler.py`:

- `KEYWORDS`: List of terms to search (e.g., `["trump", "fed", "bitcoin"]`).
- `START_DATE` / `END_DATE`: The time range for historical data.
- `GRANULARITY`: Data resolution (`1m`, `10m`, `1h`, `1d`).
- `OUTPUT_CSV`: Destination file for the collected data.

Run the script:
```bash
python crawler.py
```

### 2. Analysis & Visualization (`judger.py`)

Once you have a dataset (e.g., `polymarket_dataset_final.csv`), run the judge script to generate reports and plots:

```bash
python judger.py
```

- **Statistical Report**: Prints keyword distribution, market counts, and data density to the console.
- **Visualizations**: Generates price history plots for the top 5 most active markets and saves them in the `market_plots/` directory.

### 3. Interactive Search (`test.py`)

For a more manual approach or to test specific tokens:

```bash
python test.py
```
Follow the interactive prompts to search for an event, select a market/outcome, and define a custom time range for data extraction.

## Data Output

The collected data is saved in a CSV format with the following columns:
- `event_title`: Name of the parent event.
- `market_question`: The specific question being bet on.
- `outcome`: The betting option (e.g., "Yes", "No").
- `datetime_utc`: Timestamp of the data point.
- `price`: The probability price (0 to 1).
- `keyword`: The search term used to find this event.
- `token_id`: Unique identifier for the outcome token.

## Directory Management

- `market_plots/`: Generated charts are stored here.
- `polymarket_scraper.log`: Logs for the crawler's activity.
